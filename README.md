# Intro to HRI Class Project

## Overview
A Human-Robot Interaction (HRI) project developed as the final project for the **Introduction to Human Robot Interaction** course at Carnegie Mellon University. This project involves programming the Misty robot to perform interactive tasks and behaviors.

---

## Prerequisites
- Misty robot (v2 or compatible version)
- Visual Studio Code (VSC)
- Misty Skills extension for VSC
- WiFi connection to the same network as Misty
- Misty robot IP address

---

## Getting Started

### 1. Connect to Misty via WiFi
- Ensure your computer and Misty robot are connected to the same WiFi network
- Note the IP address of your Misty robot (check the Misty mobile app or robot display)

### 2. Open Project in VSC
- Open the project folder in Visual Studio Code

### 3. Upload and Run Code

**Windows:**
```
Ctrl + Shift + P
```

**Mac:**
```
Cmd + Shift + P
```

This opens the command palette. You'll see these options:

- **Upload and Run** - Uploads your code and executes it immediately
- **Upload** - Uploads your code without running it
- **Stop** - Stops the currently running skill

### 4. Enter Misty's IP Address
When prompted, enter your Misty robot's IP address

---

## Troubleshooting

- **Connection Issues:** Verify Misty and your computer are on the same WiFi network
- **Upload Failures:** Check that the IP address is correct and Misty is powered on
- **Runtime Errors:** Check the VSC debug console for error messages
